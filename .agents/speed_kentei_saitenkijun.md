# 日本情報処理検定協会主催　文章入力スピード認定試験　採点基準

## 採点基準

| 規則               | 内容                                                                        | 具体例                                                   |    ミス数の考え方 |
| ------------------ | --------------------------------------------------------------------------- | -------------------------------------------------------- | ----------------: |
| 誤字：単体         | 問題文と違う文字を打つと、問題文の1文字につき1ミス                          | 「 __使__ 用した紙の」→「 __私__ 用した紙の」            |                 1 |
| 誤字：入力が長い   | 漢字・かなの違いも誤字扱い                                                  | 「 __高__ く評価されて」→「 __たか__ く評価されて」      |                 1 |
| 誤字：入力が短い   | 置き換わった文字数分がミス                                                  | 「暮らしの __さまざま__ な」→「暮らしの様々な」          |                 4 |
| 全角・半角         | 数字・英字・カタカナ・記号は半角にしない。半角がある場合はまとめて1ミス     | 「４０」→「40」、「Ｊ．Ｐａｌｍｅｒ」→「J.Palmer」       | 半角由来は全体で1 |
| 段落の始め         | 段落頭は問題文どおり、全角1字分空ける                                       | 「 __　__ 日本は昔から…」を「日本は昔から…」にしてしまう |                 1 |
| 段落の終わり       | 段落末は必ず改行する                                                        | 1段落目の終わりで改行せず、次段落を続けて打つ            |      1箇所ごとに1 |
| 段落頭＋改行漏れ   | 改行忘れと段落末スペース1文字忘れをどちらもカウントし、2ミスとする          | 「…だと思います。ニッケン印刷株式会社…」のように続ける   |                 2 |
| 強制改行           | 段落末以外で自分で改行するとミス                                            | 「…ました。」の後で段落途中なのにEnterを押す             |      1箇所ごとに1 |
| 余分なスペース     | 余計なスペースは、スペース数にかかわらず1ミス                               | 「そして、それらは」→「そして、 __　__ それらは」        |                 1 |
| 余分な文字         | 問題文にない文字を入れると、その文字数分ミス                                | 「できる限り伸ばす」→「できる限り __に__ 伸ばす」        |                 1 |
| 同じ文字の再入力   | 同じ語句を余分に重ねると、その文字数分ミス                                  | 「紙の再生率」→「紙の __再生の__ 再生率」                |                 3 |
| 脱字               | 抜けた文字数分ミス                                                          | 「今後は __この__ 数字を」→「今後は数字を」              |                 2 |
| 転倒               | 文字順を入れ替えると、入れ替わった文字数分ミス                              | 「必要だと」→「必要 __とだ__ 」                          |                 2 |
| 語句単位の転倒     | 語句の順序が入れ替わっても、該当文字数分ミス                                | 「株式会社」→「 __会社株式__ 」                          |                 4 |
| 長音記号とハイフン | 長音記号「ー」とハイフン「－」の混用は減点なし                              | 「リサイクルー」系の長音表記で混ざる場合                 |      原則ミスなし |
| 読点とカンマ       | 「、」と「，」は、どちらか一方に統一されていれば許容。混在すると全体で1ミス | 全部「、」または全部「，」なら可。両方混ぜると不可       |           混在で1 |

## UltiTypeにおける特例

- 提出した文章の誤りを減点対象とする。誤りを入力したあと消した場合は、特に減点などは行わない。
- 行段落の頭は、スペースが空いている課題と空いていない課題がある。検定本番ではすべての段落の頭にスペースがあるが、UltiTypeでは原文のスタイルを尊重する。
- ランク算定用の誤字数と、検定仮点数算出用の誤字数は別でカウントする。
  - 検定仮算出用の文字数は、『入力文字数-「ミス数」*2』とする。
  - ランク算定用の誤字率は、『1-(有効入力文字を最小のローマ字にしたもの/入力文字数を最小のローマ字にしたもの)』とする。
  - 最小ローマ字とは、課題文のふりがなを入れるにあたって必要になる最小長のローマ字入力文字列である。例えば、「しちりん」は「sitirin」や「shichirin」などの候補があるが、「sitirin」が最小であるため7文字扱いとなる。

## 例

### 課題例文

使用した紙が高く評価されて、できる限り伸ばすことで株式会社がリサイクルーできた。

### 入力

使用した使用した上がたかく評価されて、できる限り伸ばすことで会社株式がリサイクル-できた。

### 採点

#### ミス数（検定入力文字数算出用）

- 「使用した」→「使用した使用した」＝-4
- 「高く」→「たかく」＝-1
- 「紙が」→「上が」＝-1
- 「株式会社」→「会社株式」＝-4
- 「リサイクルー」→「リサイクル-」＝0（減点なし）
