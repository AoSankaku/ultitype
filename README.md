# UltiType

UltiType は、高速タイピスト向けの日本語・英語タイピング練習／レーティングアプリです。現在のリリース段階は `2026.7.0-beta2` です。

## 主な機能

- 正確性・安定性・速度に焦点を当てた3種類の練習モード
- IMEなし／IMEありの本番レーティングモード
- 日本語と英語の課題文
- ランク、セッション履歴、表示・入力方式・サウンド設定
- ブラウザー内に保存されるローカルプロフィール

## 必要環境

- Bun 1.3.14
- デスクトップ向けの現行ブラウザー

## 開発

依存関係を再現可能な形でインストールします。

```sh
bun install --frozen-lockfile
```

開発サーバーは次のコマンドで起動します。

```sh
bun run dev
```

品質チェックは個別に実行できます。

```sh
bun run typecheck
bun run lint
bun test
bun run test:coverage
bun run build
```

本番ビルドは Next.js の静的エクスポートとして `out/` に生成されます。

## ベータ版の既知の制約

- 画面幅 520px 未満は正式な対象外で、アプリ内に警告が表示されます。
- ランク、履歴、設定はブラウザーのローカルストレージに保存されます。アカウント同期、端末間同期、クラウドバックアップはありません。
- ブラウザーデータを消去すると保存内容も失われます。設定画面からユーザーデータと設定を個別に消去できます。
- 本番モードは練習モードの仮レーティングが A0 以上になるまで利用できません。
- フォントは Google Fonts から取得するため、ネットワークやコンテンツブロッカーの状態によって代替フォントが使われる場合があります。
- 実ブラウザーを使った一連のE2Eテストは未整備です。現時点ではユニット／コンポーネントテストと手動スモークテストで検証しています。
