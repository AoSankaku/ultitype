# 長文の豆知識と参照資料

2026-10-25、既存の9テーマについて、各課題ファイルの長文1～3本目（計27本）を豆知識を含む内容に改稿した。各テーマ10本・各300～600文字を維持し、4～10本目と短文は維持した。

以下の番号は、各テーマの長文課題ファイル内の順番を指す。日常の場面や会話は創作であり、事実として述べる豆知識は対応する資料で確認した。今後これらの事実を変更する際は、参照資料と本文の対応も更新する。
